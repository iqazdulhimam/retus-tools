🌐 Pod Network

Testnet live dari proyek berpendanaan $10M (a16z CSX, 1kx). Alurnya: waitlist → connect wallet di testnet → verifikasi X → dapat 10.000 testnet USD → trading testnet.

100% Gratis±20 menitLevel: PemulaReward: Spekulatif
🎣 Waspada phishing

Proyek populer = banyak situs tiruan. Verifikasi domain persis (pod.network dan test.pod.network) sebelum connect wallet. Jangan klik link dari DM / komentar.

🎒 Siapkan dulu

Wallet EVM + akun X (Twitter) untuk verifikasi. Email untuk waitlist.

1

Daftar waitlist

Buka pod.network (ketik manual) → daftar waitlist dengan email-mu.

2

Buka testnet

Ketik manual: test.pod.network. Pastikan domainnya persis seperti ini.

3

Connect wallet

Hubungkan wallet-mu ke aplikasi testnet. Periksa ulang URL di address bar setelah halaman termuat.

4

Verifikasi X

Lakukan verifikasi akun X sesuai instruksi di dApp. Setelah terverifikasi, kamu menerima 10.000 testnet USD.

5

Trading testnet

Gunakan saldo testnet untuk trading / mencoba fitur yang tersedia. Ini murni testnet — tidak ada uang asli yang bergerak.

6

Tetap aktif

Kembali berkala dan coba fitur baru saat testnet diupdate. Aktivitas berkelanjutan biasanya dinilai lebih tinggi.

⚠️ Catatan

Token & tanggal TGE belum diumumkan (spekulatif). Semua dana di testnet tidak bernilai — jangan tertipu orang yang "membeli" testnet USD.
